Update

Use the dedicated OTA Update page to flash new firmware to the M5Dial. Firmware files are .bin files built with PlatformIO.

Web Interface Files

Individual web UI files (HTML, JS, CSS) can be uploaded here. Use "Upload web file" on the right to replace a file in SPIFFS without reflashing the full filesystem.

Full Filesystem Update

To update all web files at once, run pio run -e m5stack-dial --target uploadfs from PlatformIO. See the GitHub repository for build instructions.

⚠ Unsaved changes — click Save to Flash to persist across power cycles.
